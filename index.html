four

A live sampler for norns with four stereo tracks. Catch what your synth or drum machine plays, and the recording turns into a new instrument in your hands.

Scroll to put it together

This is a pocket-sized version of the norns shield, built around a Raspberry Pi Compute Module 4. It is still in design. four runs on any norns.

Switch it on.

Twelve pages, three keys, three encoders

E1 turns the page. K2, K3, E2 and E3 do what the bottom of the screen says, so the screen is the manual. Hold K1 for a second layer.

On every page

K1 + E1
Pick track 1 to 4. TAKE, VOICE, FILTER and EFFECT follow it.
K1 + K2
Stop everything, and start it again where it was.
K1 + K3
A tap turns every effect off. A long hold erases what the page holds.

Install

In maiden, type this line, then select SYSTEM > RESTART.

;install https://github.com/Alejo-end/four
